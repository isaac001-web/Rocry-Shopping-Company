Sales Data Analysis for Rocry Shopping Company
 1. Introduction
Rocry Shopping Company is a growing e-commerce business. This project focuses on cleaning and analyzing sales data to generate insights into customer behavior, sales distribution, and market performance. The analysis helps identify key customer segments and high-performing regions to support business decision-making.
 2. Data Cleaning
The dataset was cleaned and prepared for analysis using the following steps:
•	Ensured all data fields were properly structured into separate columns
•	Replaced gender codes:
o	M → Male
o	F → Female
•	Converted marital status values:
o	0 → Single
o	1 → Married
•	Removed unnecessary columns (Column N and Column O)
•	Replaced missing values in the Amount column with 0 to account for unsuccessful orders

 9. Dashboard Visualization
A dashboard was created using a Pivot Chart to provide a visual summary of the analysis.
•	Age Group is displayed on the horizontal axis
•	Sum of Amount is shown on the vertical axis
•	Gender is used as the legend for comparison
•	Marital Status adds an additional layer of segmentation
 
A Zone slicer was included to enable interactive filtering by region. This allows users to explore sales patterns dynamically and gain deeper insights into customer behavior across different zones.
The dashboard effectively highlights key trends and supports data-driven decision-making.

10. Conclusion
The analysis shows that Rocry Shopping Company’s revenue is largely driven by young and middle-aged customers, especially females aged 26–35. Additionally, certain states such as Uttar Pradesh and Maharashtra contribute significantly to overall sales.
By focusing on these high-performing customer segments and regions, the company can optimize its marketing strategies, improve customer engagement, and increase overall revenue.
